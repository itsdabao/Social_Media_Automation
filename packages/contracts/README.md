# Public contracts package

The `@social-media/contracts` package exports `@social-media/contracts/health`, containing `ApiHealthResponse` and its runtime validator. The NestJS controller uses the type, and the Next.js health connection uses the validator. Further contracts and any schema-library selection will be added with their owning features. See the [web foundation guide](../../docs/guides/web-foundation.md).

Group public contracts by feature under `src/<feature>/`. The package can be consumed by web and API. Map transport shapes to backend inputs at the API boundary.

Keep this package independent of NestJS, Temporal, database models, backend internals, app code, and provider credentials. Internal workflow contracts belong with the owning backend application module. `npm run check:contracts` at the root compiles the public exports, lints source, and runs the focused contract tests. Build output is ignored under `dist/` and regenerated by `npm run build --workspace @social-media/contracts`.
